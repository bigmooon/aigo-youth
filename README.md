# AIGO-V2: 임대차 계약서 위험 조항 탐지 시스템 (근거제시형)

임대차 계약서의 위험 조항을 AI와 법령 기반으로 탐지하고 근거와 함께 제시하는 시스템입니다.

---

## 법률 자문 고지

**본 서비스는 법률 자문이나 법적 조언을 제공하는 서비스가 아닙니다.**

법령·판례·법령해석례에 기반한 정보 안내 서비스이며, 구체적인 법적 판단이 필요한 경우 반드시 전문가와 상담하시기 바랍니다.

## v1 → v2: 무엇을, 왜 바꿨나

**계보**: [aigo-ai](https://github.com/aigo-youth/aigo-ai) (3차 팀 프로젝트, RAG 챗봇 MVP) → [aigo-server](https://github.com/SKNETWORKS-FAMILY-AICAMP/SKN24-4th-6Team) (4차, Django/FastAPI 웹 서비스 확장) → **aigo-v2** (개인 재설계)

v1은 "물어보면 답하는" Q&A 챗봇이었습니다. 하지만 임차인은 **뭐가 위험한지 몰라서 질문 자체를 못 합니다.** 그래서 v2는 안 물어봐도 계약서 전체를 스캔해 근거를 찾아주는 탐지 시스템으로 방향을 바꿨습니다.

| | v1 (팀) | v2 (개인) |
|---|---|---|
| 입력 | 사용자가 특약을 타이핑 | 계약서 파일 업로드 (PDF 우선) |
| 동작 | Q&A | 조항 자동 분해 → 조항별 근거 매칭 → 리포트 |
| 출력 | 대화 답변 | 발견 유형 리포트 + 후속 Q&A |
| 품질 관리 | 평가 노트북 | 골든셋 기반 자동 평가 + CI 회귀 |
| 정체성 | RAG 챗봇 | 정확도를 측정하는 탐지 시스템 |

### 왜 "판정"이 아니라 "근거 제시"인가

"위험/주의/무난" 등급 판정은 비변호사의 법률 사무(변호사법 제109조) 소지와 오판 책임 문제가 있어 채택하지 않았습니다. 시스템은 조항별로 검증 가능한 사실만 제시합니다 — ⚖️ 법령과 다름(조문 ID), 📚 분쟁 전례 있음(판례 번호), 📋 표준계약서와 상이(조항 번호). "위험하다"는 시스템이 말하지 않고, 법령·판례를 옆에 놓아주면 사용자가 판단합니다.

부수 효과: 라벨의 ground truth가 "위험 등급(주관)"이 아닌 "조문 상충 여부(객관)"가 되어 평가를 방어할 수 있습니다.

전체 설계 결정은 [설계 스펙](docs/superpowers/specs/2026-07-06-aigo-v2-design.md) 참고.
